# Design rationale

Reference: [IBM Carbon typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/style-strategies), [data tables](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/specifications).

Productive use: a consistent grid, visible labels, compact tables, meaningful status colors, predictable actions, accessible focus states. Editorial use: restrained IBM Plex Serif headings for the explanatory sections. Neutral surfaces, a single dark green action color and subdued warning tones reflect the financial support context. Fonts are local assets, not remote runtime dependencies.

No chat bubbles, sparkling assistant avatar, decorative gradient, fake usage graph or unsupported success metric. The working surface leads with the ticket, evidence and reviewer decision. The supporting surfaces explain what exists, what is planned, why it was chosen, and what would trigger a change.

Mobile layout changes the sidebar into a menu, stacks ticket/result panels, wraps classification, and allows horizontal scrolling only inside the evaluation table. Reduced-motion preferences are respected.
